# Politica di sicurezza

## Versioni supportate

Le correzioni di sicurezza vengono applicate all'ultima release pubblicata della serie 4.1.x.
Le release precedenti possono non ricevere aggiornamenti.

| Versione | Supportata |
| --- | --- |
| Ultima 4.1.x | Sì |
| Versioni precedenti | No |

## Segnalare una vulnerabilità

Non aprire issue pubbliche per vulnerabilità sospette o confermate.

Usa la funzione **Report a vulnerability** nella scheda **Security** del repository per inviare
una segnalazione privata. Includi, se possibile:

- versione o commit interessato;
- descrizione e impatto potenziale;
- passaggi minimi per riprodurre il problema;
- eventuale proof of concept, senza dati reali o segreti;
- proposta di mitigazione, se disponibile.

Confermeremo la ricezione entro 5 giorni lavorativi e forniremo un primo aggiornamento entro
10 giorni lavorativi. La tempistica di correzione dipende da gravità, impatto e complessità.
Chiediamo di non divulgare pubblicamente i dettagli prima che sia disponibile una correzione o
sia stata concordata una data di pubblicazione.

## Ambito

Sono in ambito la distribuzione italiana di OpenCart, il relativo archivio di release e
l'automazione di build e installazione. Le vulnerabilità presenti nel progetto OpenCart
upstream o in dipendenze di terze parti devono essere segnalate anche ai rispettivi
manutentori; se influenzano questa distribuzione, includile comunque nella segnalazione privata.
